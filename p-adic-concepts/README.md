This repository contains timestamped preprints of version of the paper *Learning classification on hierarchical ultrametric domains: generalization bounds in the p-adic setting* by Joel Ratsaby.

Each preprint includes:

- the PDF manuscript
- an OpenTimestamps proof file (.ots)
- a timestamp certificate
- README with details

The timestamps anchor the document hash in the Bitcoin blockchain,
providing cryptographic proof that the document existed at or before
the recorded time.
